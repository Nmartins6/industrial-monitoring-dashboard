# Industrial Monitoring Dashboard

Dashboard de monitoramento em tempo real para uma máquina industrial.

## Status do projeto

O projeto está na etapa inicial de configuração do monorepo.

Ainda não existem aplicações frontend ou backend executáveis.

## Objetivo

Construir uma solução de monitoramento industrial com:

- visualização do estado de uma máquina;
- métricas de temperatura, RPM e tempo de operação;
- atualização simulada em tempo real;
- histórico de métricas;
- alertas operacionais;
- indicadores de eficiência industrial;
- frontend responsivo;
- backend estruturado;
- testes automatizados;
- execução com Docker.

## Tecnologias planejadas

- TypeScript
- React
- Tailwind CSS
- Node.js
- SQLite
- Jest
- React Testing Library
- Turborepo
- Docker

## Requisitos do ambiente

- Node.js 24
- pnpm 11
- Docker
- Docker Compose

## Estado atual

A fundação do repositório está sendo configurada.

Os comandos de desenvolvimento, testes e build serão documentados quando estiverem implementados.
